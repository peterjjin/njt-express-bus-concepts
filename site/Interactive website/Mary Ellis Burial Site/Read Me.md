# Mary Ellis Burial Site alternative

## Concept 1 · Rutgers via Mary Ellis Burial Site P&R

SHI Stadium → Albany @ George (HELIX access) → Burnet Street ramp → Route 18 south → US 1 / Woodbridge Avenue loop → proposed Mary Ellis Burial Site P&R → Exit 9 → NJ Turnpike → Secaucus Junction.

## Concept 2 · 8A express with optional Mary Ellis Burial Site P&R

South Brunswick 8A P&R → NJ Turnpike → Secaucus Junction. Optional Mary Ellis Burial Site pickup leaves the Turnpike at Exit 9, uses the US 1 / Woodbridge Avenue loop to reach the rear lot, then returns through Exit 9.

## Concept 3 · Molly Pitcher P&R via Exit 8

Proposed Molly Pitcher Service Area P&R → assumed rear-gate opening → Half Acre Road → US 130 → Route 133 → Turnpike Exit 8 northbound → Secaucus Junction. Optional pickups: South Brunswick Exit 8A P&R and Mary Ellis Burial Site at Exit 9. No direct northbound entry from the southbound service area is assumed.

## Concept 3 access assumption

Molly Pitcher is a southbound service area. This concept assumes authorization to open the gated rear service-road connection to Half Acre Road; it is not existing public access. Buses use local roads and enter the Turnpike northbound at Exit 8. P&R use, coach access, gate/security changes and parking capacity are unapproved.

The optional Exit 8A and Exit 9 pickups can be toggled independently. GeoJSON/CSV variants: core, optional (Exit 9), optional_8a (Exit 8A), optional_both (both pickups). No new connector is certified as an existing public road.

Northbound planning concept, not an approved operating route. Road connectors use a car-routing profile, not bus-clearance or turning-path analysis. Confirm property agreements, cemetery setbacks/protection, safe walking access, parking and boarding layout, traffic control, return routing, Secaucus bay and layover. No journey-time or ridership estimate is asserted. GTFS reuse denotes geometry, not an existing through service.
